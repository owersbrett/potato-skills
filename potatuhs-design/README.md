# potatuhs-design

> The blank page is the reason your brand book doesn't exist. This removes it.

A skill that composes a complete **brand-guidelines website** with you: a
guided interview through every component of a brand system — brand overview,
logo system, color, typography, iconography, photography, mascots, UI
components, shadows & borders, motion, layout, voice & tone, sub-brands, and
governance — then generates the artifact:

- **`DESIGN.md`** — the canonical brand spec (the SSOT),
- **`tokens.css`** — every value as CSS custom properties,
- **the site** — a single-page-scroll, print-to-PDF guidelines document that
  renders the spec (sidebar nav, scroll-synced highlighting, live component
  demos).

Extracted from the in-production Potatuhs brand system. The universal
*categories* were kept and made exhaustive; the Potatuhs-specific *instances*
(the 52-card mascot deck, the marquee-carousel signature, the division icon
taxonomy) were removed. Any brand can fill this skeleton in.

## Files

| File | Job |
|---|---|
| [`SKILL.md`](./SKILL.md) | Trigger + procedure: intake → section-by-section interview → contract → site → handoff. |
| [`SECTIONS.md`](./SECTIONS.md) | The rubric: all 15 sections of a brand system, with what to ask and what each page renders. |
| [`SITE.md`](./SITE.md) | The generated site's architecture contract: shape, nav, tokens, shared components, print, definition of done. |
